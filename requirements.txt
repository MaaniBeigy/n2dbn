# major version and change a stored result without any source changing, which
# is how the networkx-temporal breakage below reached a rebuilt image.

# stays within a compatible range rather than pinning an exact build.

# The published forecasting splits ship as parquet, which pandas reads only
# through an engine.
pyarrow>=15,<25
pytest>=7.0,<10
pytest-cov>=4.0,<8
pyAgrum>=1.9,<4
pgmpy>=1.0,<2
pycvcqv==0.7.4
